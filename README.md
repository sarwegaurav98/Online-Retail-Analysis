## 📁 Project Structure

```
Online Retail Data Analysis/
├── Online Retail.xlsx                  ← original UCI dataset (23 MB)
├── clean_analyze.py                    ← Python pipeline → run this first
├── build_excel.py                      ← generates retail_analysis.xlsx
├── build_tableau.py                    ← generates retail_dashboard.twbx
├── build_report.py                     ← generates the .docx report
├── dashboard.py                        ← Streamlit interactive dashboard
├── retail_analysis.xlsx                ← Excel workbook (7 sheets + charts)
├── retail_dashboard.twbx               ← Tableau packaged workbook
├── Online_Retail_Project_Report.docx   ← full project report
├── requirements.txt                    ← Python dependencies
├── .gitignore
└── output/                             ← analysis CSVs (generated by pipeline)
    ├── kpi_summary.csv
    ├── monthly_revenue.csv
    ├── country_revenue.csv
    ├── top10_products.csv
    ├── rfm_segments.csv
    ├── pareto_customers.csv
    ├── cohort_retention.csv
    ├── churn_summary.csv
    ├── returns_by_product.csv
    ├── returns_by_country.csv
    ├── returns_summary.csv
    └── data_quality_log.csv
```

> `output/cleaned_data.csv` (36 MB) is excluded via `.gitignore`. It is regenerated by `clean_analyze.py`.

## 🚀 Quick Start

### 1 · Install dependencies
```bash
pip install -r requirements.txt
```

### 2 · Run the analysis pipeline
```bash
python clean_analyze.py
```
Reads `Online Retail.xlsx`, cleans the data, computes all four objectives, and writes all CSVs to `output/`.

### 3 · Launch the Streamlit dashboard
```bash
streamlit run dashboard.py
```
Opens at **http://localhost:8501**

### 4 · (Optional) Rebuild the Excel workbook
```bash
python build_excel.py
```

### 5 · (Optional) Rebuild the Tableau workbook
```bash
python build_tableau.py
```

### 6 · (Optional) Rebuild the project report
```bash
python build_report.py
```

## 📊 Objectives & Findings

### 1 · Revenue Performance

| KPI | Value |
|-----|-------|
| Total Revenue | **£10,253,975** |
| Total Orders | **19,776** |
| Average Order Value | **£518.51** |
| Unique Customers | **4,334** |
| Countries | **38** |

- **Peak month:** November 2011 — £1,453,263 (holiday season)
- **UK dominance:** 85.1% of all revenue
- **Top product:** REGENCY CAKESTAND 3 TIER — £174,157

### 2 · Customer Segmentation (RFM)

| Segment | Customers | Revenue Share |
|---------|-----------|---------------|
| Champions | 956 | **65.3%** |
| Loyal Customers | 1,007 | 16.4% |
| At Risk | 1,144 | 11.4% |
| Lost | 561 | 3.4% |
| New Customers | 319 | 1.6% |

**Pareto:** Top 26.1% of customers generate 80% of revenue.

### 3 · Retention & Churn

- **Churn rate (90-day):** 33.4% (1,449 customers)
- **Best cohort:** Dec 2010 — 36.5% month-1 retention
- **Average month-1 retention:** ~21% across all cohorts

### 4 · Returns & Data Quality

- **Return rate:** 7.76%
- **Revenue lost to returns:** £896,812
- **Data cleaned:** ~150,000 rows removed from 541,909 raw records

## 🗂️ Dataset

**Source:** [UCI Machine Learning Repository – Online Retail](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

| Field | Description |
|-------|-------------|
| InvoiceNo | Invoice number (prefix 'C' = cancellation) |

| Description | Product name |
| Quantity | Units per transaction |
| InvoiceDate | Date and time |
| UnitPrice | Unit price in GBP (£) |

| Country | Customer country |
